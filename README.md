# Personal Portfolio Website

## Project Overview

This project is a personal portfolio website created using HTML, CSS, and JavaScript. The website introduces me professionally, showcases my skills and projects, and provides visitors with an easy way to learn more about me and contact me.

---

# Target Audience

The target audience for this website includes employers, internship recruiters, professors, classmates, and anyone interested in learning more about my background and projects.

---

# Content Strategy

The website is divided into four pages:

- Home
- About Me
- Projects
- Contact

Each page focuses on a different aspect of my portfolio while maintaining a consistent design.
